# Venue maintenance windows

Minutes inside a venue-announced maintenance window are left out of the coverage denominator
(DQ-10) and reported separately (`maintenance_minutes` in the day's DQ notes). Add a row only
with the venue's own announcement as the source. The parser reads table rows of the form
`| venue | YYYY-MM-DD HH:MM | YYYY-MM-DD HH:MM | source |` (start and end in UTC).
